### 🏎️ NFSMW Recompiled

**Static native recompilation of Need for Speed: Most Wanted (2005) — Xbox 360**

</div>

A project exploring **static recompilation and native execution** of the Xbox 360 version of Need for Speed: Most Wanted.

The original PowerPC code is translated ahead of time into C++ and compiled into a native x86-64 application rather than being interpreted at runtime.

The project works together with the **ReXGlue SDK**, providing the surrounding Xbox 360 runtime, filesystem, audio, input and graphics infrastructure.

**Technologies & concepts**

`C++` `Python` `CMake` `Ninja` `Clang` `Direct3D 12` `PowerPC` `Xbox 360` `Static Recompilation`

**Areas explored**

* PowerPC → native x86-64 recompilation
* Runtime integration
* Xbox 360 system calls
* Graphics through Direct3D 12
* EDRAM emulation
* Audio systems
* Input
* Save systems
* Resolution scaling
* Frame pacing
* Build automation
* SDK patching
* Diagnostic tooling

The repository also contains extensive technical documentation covering architecture, compilation, patches, performance and debugging.

[**→ View NFSMW Recompiled**](https://github.com/madelrandel-blip/NFSMW-Recompiled)
